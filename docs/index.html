Install Daybreak

For the 2.8-inch ESP32-2432S028 board with a 240 × 320 ILI9341 display.

Connect the board with a data USB cable, then use desktop Chrome or Edge.

This browser cannot use Web Serial. Open this page in desktop Chrome or Edge. Open this installer over HTTPS to connect to your board.

After installation, follow the Wi-Fi setup on the screen. Erasing the device removes saved settings.
